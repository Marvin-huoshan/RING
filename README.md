# RING

**Anonymous repository for the submission to IEEE S&P 2026:** *Your Privacy My Cloak: Backdoor Attack on Differentially Private Federated Learning*

## Description

**RING** allows malicious clients to jointly inject backdoors and remain effective under DP-FL even in the presence of state-of-the-art defenses. By evaluating multiple defenses and comparing against baseline attacks, it highlights aggravated privacy risks and underscores the urgent need for stronger mitigation strategies.
